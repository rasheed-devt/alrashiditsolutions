### Publish on GitHub Pages
1. Create a GitHub repository, e.g. `al-rashid-it-solutions`.
2. Upload the files in this folder to the repository.
3. Push to the `main` branch.
4. In GitHub open **Settings → Pages**.
5. Select **GitHub Actions** as the source, or use the included workflow.
6. GitHub will publish the site and show the live URL.

The site is static HTML/CSS/JavaScript, so no hosting server or database is required.
